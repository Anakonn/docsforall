# 토큰 캐싱 및 비용 최적화

Gemini CLI는 API 키 인증(Gemini API 키 또는 Vertex AI) 사용 시 토큰 캐싱을 통해 API 비용을 자동으로 최적화합니다. 이 기능은 이전 시스템 지시사항과 컨텍스트를 재사용하여 후속 요청에서 처리되는 토큰 수를 줄입니다.

**토큰 캐싱이 사용 가능한 경우:**

- API 키 사용자 (Gemini API 키)
- Vertex AI 사용자 (프로젝트 및 위치 설정 포함)

**토큰 캐싱이 사용 불가능한 경우:**

- OAuth 사용자 (Google 개인/엔터프라이즈 계정) - Code Assist API는 현재 캐시된 콘텐츠 생성을 지원하지 않음

`/stats` 명령어를 사용하여 토큰 사용량과 캐시된 토큰 절약을 확인할 수 있습니다. 캐시된 토큰이 사용 가능한 경우 통계 출력에 표시됩니다.
