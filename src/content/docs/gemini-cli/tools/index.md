# Gemini CLI 도구

Gemini CLI는 Gemini 모델이 로컬 환경과 상호작용하고, 정보를 접근하며, 다양한 작업을 수행할 수 있도록 여러 내장 도구를 제공합니다. 이 도구들은 CLI의 기능을 확장하여 단순 텍스트 생성 이상의 폭넓은 작업을 지원합니다.

## Gemini CLI 도구 개요

Gemini CLI에서 도구란, Gemini 모델이 실행을 요청할 수 있는 특정 기능 또는 모듈을 의미합니다. 예를 들어, "`my_document.txt` 내용을 요약해줘"라고 요청하면, 모델은 해당 파일을 읽기 위해 `read_file` 도구 실행을 요청합니다.

코어 컴포넌트(`packages/core`)가 이 도구들을 관리하며, 도구 정의(스키마)를 모델에 제공하고, 요청 시 실행 후 결과를 모델에 반환합니다.

이 도구들은 다음과 같은 기능을 제공합니다:

- **로컬 정보 접근:** 파일 시스템 접근, 파일 읽기, 디렉토리 목록 조회 등
- **명령 실행:** `run_shell_command` 등으로 셸 명령 실행(안전장치 및 사용자 확인 포함)
- **웹 상호작용:** URL에서 콘텐츠 가져오기
- **액션 수행:** 파일 수정, 새 파일 작성 등(대부분 확인 절차 포함)
- **응답 근거 제공:** 실시간/로컬 데이터를 활용해 더 정확하고 맥락에 맞는 답변 생성

## Gemini CLI 도구 사용법

1. CLI에 프롬프트 입력
2. CLI가 프롬프트를 코어에 전달
3. 코어가 프롬프트, 대화 이력, 사용 가능한 도구 목록/스키마를 Gemini API에 전달
4. Gemini 모델이 도구 사용 필요 판단 시, 특정 도구와 인자를 포함한 요청 반환
5. 코어가 도구 요청을 검증하고(민감 작업은 사용자 확인 후) 실행
6. 도구 실행 결과를 모델에 반환
7. 모델이 결과를 활용해 최종 답변 생성, CLI에 표시

도구 실행 시 CLI에서 관련 메시지(성공/실패 등)를 확인할 수 있습니다.

## 보안 및 확인

파일 시스템 변경, 명령 실행(`write_file`, `edit`, `run_shell_command` 등) 도구는 안전을 위해:

- **확인 요청:** 민감 작업 전 사용자에게 실행 내용 안내 및 확인 요청
- **샌드박싱:** 모든 도구는 샌드박스 환경에서 제한적으로 동작(자세한 내용은 [/gemini-cli/sandbox] 참고). 샌드박스 내에서만 MCP 서버 등 도구 사용 가능

확인 메시지를 꼼꼼히 검토한 후 진행하세요.

## Gemini CLI 도구 분류 및 더 알아보기

- **[파일 시스템 도구](/gemini-cli/tools/file-system):** 파일/디렉토리 읽기, 쓰기, 검색 등
- **[셸 도구](/gemini-cli/tools/shell) (`run_shell_command`):** 셸 명령 실행
- **[웹 가져오기 도구](/gemini-cli/tools/web-fetch) (`web_fetch`):** URL 콘텐츠 가져오기
- **[웹 검색 도구](/gemini-cli/tools/web-search) (`web_search`):** 웹 검색
- **[멀티 파일 읽기 도구](/gemini-cli/tools/multi-file) (`read_many_files`):** 여러 파일/디렉토리 내용 읽기(`@` 명령 등에서 사용)
- **[메모리 도구](/gemini-cli/tools/memory) (`save_memory`):** 세션 간 정보 저장/불러오기

또한,
- **[MCP 서버](/gemini-cli/tools/mcp-server):** Gemini 모델과 로컬 환경/외부 서비스(API 등) 연결 브릿지 역할
- **[샌드박싱](/gemini-cli/sandbox):** 모델과 환경을 격리해 위험 최소화
