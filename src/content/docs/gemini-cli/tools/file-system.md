# Gemini CLI 파일 시스템 도구

Gemini CLI는 로컬 파일 시스템과 상호작용할 수 있는 다양한 도구를 제공합니다. 이 도구들은 파일 및 디렉토리의 읽기, 쓰기, 검색, 수정 등 다양한 작업을 지원하며, 대부분 민감 작업 시 사용자 확인 절차를 거칩니다.

> 모든 파일 시스템 도구는 보안을 위해 `rootDirectory`(일반적으로 CLI를 실행한 디렉토리) 내에서만 동작합니다. 경로는 절대경로 또는 rootDirectory 기준 상대경로로 해석됩니다.

## 1. `list_directory` (ReadFolder)

- **역할:** 지정한 디렉토리 내 파일/폴더 목록 조회
- **주요 파라미터:**
  - `path`(필수): 조회할 디렉토리의 절대경로
  - `ignore`(선택): 제외할 glob 패턴 목록
  - `respect_git_ignore`(선택): `.gitignore` 패턴 무시 여부(기본값: true)
- **출력:** 디렉토리/파일명 목록(디렉토리 우선 정렬)
- **확인:** 불필요

## 2. `read_file` (ReadFile)

- **역할:** 지정 파일의 내용 읽기(텍스트, 이미지, PDF 등 지원)
- **주요 파라미터:**
  - `path`(필수): 읽을 파일의 절대경로
  - `offset`, `limit`(선택): 텍스트 파일의 특정 라인 범위 지정
- **출력:**
  - 텍스트: 파일 내용(필요시 일부만)
  - 이미지/PDF: base64 인코딩 데이터
  - 기타 바이너리: 미지원 안내 메시지
- **확인:** 불필요

## 3. `write_file` (WriteFile)

- **역할:** 지정 파일에 내용 쓰기(존재 시 덮어쓰기, 없으면 생성)
- **주요 파라미터:**
  - `file_path`(필수): 쓸 파일의 절대경로
  - `content`(필수): 작성할 내용
- **출력:** 성공 메시지(덮어쓰기/생성 여부 포함)
- **확인:** 필요(변경 diff 및 사용자 승인)

## 4. `glob` (FindFiles)

- **역할:** glob 패턴으로 파일 검색(최신 수정순 정렬)
- **주요 파라미터:**
  - `pattern`(필수): 검색할 glob 패턴
  - `path`, `case_sensitive`, `respect_git_ignore`(선택)
- **출력:** 일치 파일 목록(절대경로)
- **확인:** 불필요

## 5. `search_file_content` (SearchText)

- **역할:** 정규표현식으로 파일 내용 검색(경로/패턴 필터링 지원)
- **주요 파라미터:**
  - `pattern`(필수): 검색할 정규표현식
  - `path`, `include`(선택)
- **출력:** 일치 라인(파일 경로, 라인번호 포함)
- **확인:** 불필요

## 6. `replace` (Edit)

- **역할:** 파일 내 특정 텍스트 치환(정확한 컨텍스트 필요, 다중 치환 지원)
- **주요 파라미터:**
  - `file_path`(필수): 수정할 파일의 절대경로
  - `old_string`, `new_string`(필수): 치환 전/후 텍스트(충분한 컨텍스트 포함 권장)
  - `expected_replacements`(선택): 치환 횟수(기본 1)
- **출력:** 성공/실패 메시지(치환 결과, 오류 등)
- **확인:** 필요(변경 diff 및 사용자 승인)

> 이 파일 시스템 도구들은 Gemini CLI가 로컬 프로젝트 맥락을 이해하고 상호작용할 수 있는 기반을 제공합니다.
