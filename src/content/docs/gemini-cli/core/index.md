# Gemini CLI 코어

Gemini CLI의 core 패키지(`packages/core`)는 Gemini CLI의 백엔드로, Gemini API와의 통신, 도구 관리, `packages/cli`에서 전달된 요청 처리 등을 담당합니다. Gemini CLI 전체 개요는 [/gemini-cli/] 문서를 참고하세요.

## 이 섹션의 구성

- **[코어 도구 API](/gemini-cli/core/tools-api):** 도구의 정의, 등록, 사용 방법 안내
- **[메모리 임포트 프로세서](/gemini-cli/core/memport):** @file.md 문법을 활용한 GEMINI.md 모듈화 기능 설명

## 코어의 역할

`packages/cli`가 사용자 인터페이스를 제공하는 반면, `packages/core`는 다음을 담당합니다:

- **Gemini API 연동:** Google Gemini API와 안전하게 통신, 사용자 프롬프트 전송 및 응답 수신
- **프롬프트 엔지니어링:** 대화 이력, 도구 정의, GEMINI.md의 맥락 등 다양한 정보를 활용해 효과적인 프롬프트 구성
- **도구 관리 및 오케스트레이션:**
  - 사용 가능한 도구 등록(예: 파일 시스템, 셸 명령 실행 등)
  - Gemini 모델의 도구 사용 요청 해석
  - 전달받은 인자와 함께 도구 실행
  - 실행 결과를 Gemini 모델에 반환
- **세션 및 상태 관리:** 대화 이력과 맥락을 추적해 일관성 있는 상호작용 지원
- **설정 관리:** API 키, 모델 선택, 도구 설정 등 코어 관련 설정 관리

## 보안 고려사항

코어는 다음과 같은 보안 역할을 수행합니다:

- **API 키 관리:** `GEMINI_API_KEY`를 안전하게 관리하며, Gemini API와의 통신 시 안전하게 사용
- **도구 실행:** 로컬 시스템과 상호작용하는 도구(`run_shell_command` 등)는 샌드박싱 등 안전장치를 통해 의도치 않은 변경을 방지

## 대화 이력 압축

긴 대화가 Gemini 모델의 토큰 한도를 초과하지 않도록, 코어는 대화 이력 압축 기능을 제공합니다.

모델의 토큰 한도에 근접하면, 코어가 대화 이력을 자동으로 압축해 전송합니다. 이 압축은 정보 손실 없이 토큰 수만 줄이는 방식입니다.

각 모델의 토큰 한도는 [Google AI 문서](https://ai.google.dev/gemini-api/docs/models)에서 확인할 수 있습니다.

## 모델 폴백(fallback)

기본 "pro" 모델이 속도 제한(rate limit)에 걸릴 경우, CLI는 자동으로 "flash" 모델로 전환해 작업이 중단되지 않도록 합니다.

## 파일 탐색 서비스

프로젝트 내에서 현재 맥락에 맞는 파일을 찾는 역할을 하며, `@` 명령어나 파일 접근이 필요한 도구에서 사용됩니다.

## 메모리 탐색 서비스

GEMINI.md 파일을 계층적으로 탐색해 모델에 맥락을 제공합니다. 현재 디렉토리부터 프로젝트 루트, 홈 디렉토리까지 상위로, 그리고 하위 디렉토리까지 검색합니다.

이 구조를 통해 글로벌, 프로젝트, 컴포넌트 단위의 맥락 파일을 결합해 가장 적합한 정보를 모델에 제공합니다.

[`/memory` 명령어](/gemini-cli/cli/commands)를 통해 로드된 GEMINI.md 파일의 내용을 `show`, `add`, `refresh` 할 수 있습니다.
