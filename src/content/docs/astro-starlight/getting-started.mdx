**Starlight**는 Astro 기반의 문서 웹사이트 제작을 위한 템플릿입니다. 이 가이드를 통해 `bun`을 사용하여 Starlight 프로젝트를 빠르고 쉽게 시작하고 관리하는 방법을 알아보세요.

## 프로젝트 생성하기 🚀

새로운 Starlight 프로젝트를 생성하려면 터미널에 다음 명령어를 입력하세요. 이 명령어는 Astro CLI를 사용하여 `Starlight` 템플릿으로 새 프로젝트를 설정합니다.

```bash
bun create astro --template starlight
```

이 명령어를 실행하면 프로젝트 이름과 같은 몇 가지 질문이 표시됩니다. 안내에 따라 프로젝트 설정을 완료하세요.

<Aside type='note'>
  `bun`은 매우 빠른 JavaScript 런타임 및 툴킷으로, 프로젝트 생성 및 종속성 설치 과정을 신속하게
  처리합니다.
</Aside>

## 개발 서버 실행하기 🖥️

프로젝트 생성이 완료되면, 생성된 디렉토리로 이동하여 개발 서버를 시작할 수 있습니다. 다음 명령어를 사용하세요.

```bash
bun dev
```

이 명령어는 로컬 개발 서버를 시작하며, 일반적으로 `http://localhost:4321` 주소로 사이트를 미리 볼 수 있습니다. 소스 코드를 변경하면 브라우저에서 자동으로 새로고침되어 변경 사항을 실시간으로 확인할 수 있습니다.

## 프로젝트 업그레이드하기 ⬆️

프로젝트의 Astro 및 공식 통합 패키지를 최신 버전으로 유지하려면 다음 명령어를 사용할 수 있습니다.

```bash
bunx @astrojs/upgrade
```

`bunx`는 `npx`나 `yarn dlx`와 유사하게 원격 패키지를 실행하는 명령어입니다. `@astrojs/upgrade` 패키지는 프로젝트의 `package.json` 파일을 분석하여 Astro와 관련된 패키지들을 최신 버전으로 업데이트합니다. 이를 통해 프로젝트를 항상 최신 상태로 유지하고 새로운 기능과 개선 사항을 적용할 수 있습니다.
