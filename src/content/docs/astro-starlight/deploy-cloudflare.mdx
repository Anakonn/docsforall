Astro로 만든 사이트를 Cloudflare에 배포하고 나만의 도메인을 설정하는 것은 굉장히 효율적인 방법입니다. 이 가이드는 **Cloudflare Workers** 배포 옵션을 다루며, 최종적으로 `www`가 붙거나 붙지 않은 주소를 하나로 통일하는 과정까지 상세히 안내합니다.

## 1부: Astro 프로젝트 배포하기

배포를 시작하기 전, Astro 프로젝트가 Cloudflare 환경에서 작동할 수 있도록 어댑터를 설치해야 합니다.

### 사전 준비: Cloudflare 어댑터 설치

1.  Wrangler 설치

```bash
bun add -D wrangler@latest
```

2. 터미널에서 아래 명령어를 실행해 Cloudflare 어댑터를 추가합니다.

```bash
bun astro add cloudflare
```

설치가 완료되면 `astro.config.mjs` 파일에 아래 내용이 자동으로 추가됩니다.

```js
// astro.config.mjs
import { defineConfig } from 'astro/config';
import cloudflare from '@astrojs/cloudflare';

export default defineConfig({
  adapter: cloudflare(),
});
```

이제 페이지별로 요청 시 렌더링을 활성화하거나, 기본적으로 모든 페이지를 서버 렌더링하도록 빌드 출력 구성을 output: 'server'로 설정할 수 있습니다.

`public`/ 폴더에 `.assetsignore` 파일을 생성하고 아래 내용을 추가합니다.

```txt
// .assetsignore
_worker.js
_routes.json
```

3. Wrangler 구성 파일을 생성합니다.

이제 배포할 준비가 끝났습니다. Cloudflare는 두 가지 강력한 배포 옵션을 제공합니다.

### 방법 A: Cloudflare Pages로 배포 (Git 연동, 추천)

이 방법은 GitHub, GitLab 등과 연동하여 소스코드를 푸시할 때마다 자동으로 빌드 및 배포를 진행해주는 가장 간편한 방식입니다.

1.  작성한 Astro 프로젝트 코드를 GitHub 또는 GitLab 저장소에 푸시합니다.
2.  **Cloudflare 대시보드**에 로그인 후, **컴퓨팅(Workers)** > **Workers 및 Pages** 메뉴로 이동합니다.
3.  **생성** > **Workers** 탭 > **리포지토리 가져오기** > **시작** 선택합니다.
4.  방금 코드를 푸시한 저장소를 선택하고 **설정 시작**을 누릅니다.
5.  **빌드 설정**을 다음과 같이 구성합니다.
    - **빌드 명령어**: `bun run build`
    - **배포 명령어**: `npx wrangler deploy`
6.  **저장 및 배포**를 클릭하면 잠시 후 `*.workers.dev`로 끝나는 주소로 사이트가 배포됩니다.

## 2부: 사용자 정의 도메인 설정하기

이제 배포된 사이트에 `docsforall.com`과 같은 나만의 도메인을 연결하고, `www` 주소를 정리해 보겠습니다. 배포 방식에 따라 설정법이 다릅니다.

### Cloudflare Workers에 도메인 연결

1.  **컴퓨팅(Workers)** > **Workers 및 Pages** > **레포지터리 이름** 클릭 합니다.
2.  **설정** > **도메인 및 경로** 탭으로 이동후 **+추가** 버튼을 클릭합니다.
3.  `docsforall.com`과 `www.docsforall.com`을 차례대로 추가합니다.
4.  끝입니다!

### 리디렉션 규칙 설정

- Cloudflare 대시보드 메인에서 **도메인** (`docsforall.com`)을 선택합니다.

- **규칙(Rules)** 으로 이동 후 **규칙 생성** > **리다이렉트 규칙** 을 클릭합니다.

- **WWW에서 루트로 리디렉션** 를 찾아서 **규칙 생성** 버튼을 클릭합니다.

- 아래와 같이 `docsforall.com` → `www.docsforall.com`으로 리디렉션하는 규칙을 만듭니다.

- **규칙 이름**: `WWW에서 루트로 리디렉션` 등 원하는 이름 입력

- **배포**를 클릭하여 규칙을 활성화합니다.

## 🚀 최종 완료

이 가이드를 통해 여러분의 Astro 사이트는 이제 Cloudflare에 안정적으로 배포되었으며, SEO와 사용자 경험을 모두 고려한 전문적인 도메인 설정까지 완료되었습니다.
